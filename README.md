# Tweakfast

One script line on a plain HTML site. The owner keeps the site current by clicking.

- `src/tweakfast.js`: the one line every page loads, a loader of a few hundred bytes. It fetches `src/tweakfast-editor.js`, the editor, only when the address carries `#edit=` or this browser keeps a key; readers get nothing more.
- `demo/`: a four-page garden club site to build against. Open `demo/index.html#edit=test`.
- `tools/check-*.mjs`: headless Chrome checks. Serve the repo with `python3 -m http.server 8787 --bind 127.0.0.1`; the checks that save also need `python3 tools/fake-save-server.py` (port 8788, restart it before each such check: it keeps what was saved). Then `node tools/check-<name>.mjs`.

Ring 1 (done): click text and type, swap a picture, Undo, Done (saved live by the worker; a site without one downloads the files).
Picking (done 2026-10-11): one click picks a text (solid line, the block's tools, no caret), a second click or Enter edits it with the caret where the click was; Enter and Esc end the typing and keep the text picked, Esc then lets go, a click elsewhere lets go, a picked picture or block takes the pick over; on a phone one tap picks, a second tap edits. Check: `node tools/check-select.mjs`; every check that types clicks twice (`edit()` helper).
Nothing lost (done 2026-10-12): what is not live yet is kept in this browser as it is made (each change, words still being typed, other pages, removed and new pages, with each page's saved stamp); a closed tab, a reload or a crash brings it back on the next visit as one change, said with the time, and Throw away; Done, Undo to nothing and Leave anyway end it, and going to another page of the site takes it along without a word; too large to keep is said once. Check: `node tools/check-draft.mjs`.
Loader (done 2026-10-12): the one line loads `tweakfast.js`, under 1 KB as published; it fetches `tweakfast-editor.js` (versioned by the build) only for `#edit=` or a key kept in this browser, never for `#view`; a pasted owner's link reloads a plain tab with the editor; the editor's own script tag is never saved into a page. Check: `node tools/check-loader.mjs`.
Tightening pass (done 2026-10-12): Redo, Undo past Done and a version put back change the page in place (`putContent` morphs it), so every older Undo step, the site's own scripts and the picture drag still hold their elements; the page's listeners are bound once. A menu change on every page goes through on all pages or none. Add a page is one Undo and never writes over a file outside the menu; a rename to a name in use is refused; the last of a group stays. Paste keeps line breaks, Goes-to understands a page's name, a shop's address and a phone number, Esc puts a link's address back with its words, Tab at the last text keeps it picked, typing in Japanese is left alone, a dropped photo ends the typing, see-through pictures stay see-through and a GIF stays as it is. Done can be pressed while the first change is typed and writes only pages that changed; files saved without a route hold their pictures; See the page opens the readers' page without the editor; a pasted new link revives a locked tab. Check: `node tools/check-tight.mjs` (fresh fake server).
Command palette (done 2026-10-11): Cmd+K (Ctrl+K elsewhere) opens one search over every page and every action in the sheet's place; the letters typed match in order anywhere in a word, a run in one piece ranks first; arrows move, Enter does it, Esc or a click outside closes; Cmd+K while typing commits first; Undo and Done show only with changes; no button, nothing on a phone. Motion (done 2026-10-11): one spring (`--tf-time`, `--tf-spring`) for everything that appears, a 150 ms fade for what leaves (`fade()` clears the state at once, the node goes after), sheet views slide, reduced motion turns it all off. Check: `node tools/check-palette.mjs`.
