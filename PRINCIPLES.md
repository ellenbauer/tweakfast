# Tweakfast principles

Written 2026-10-10. They describe the tool as it is today and may change as it grows.

1. The owner clicks what they see and types. No manual, no training, no new words.
2. Done is live. Undo and Versions make it safe.
3. The maker sets it up once, with one command, and leaves.
4. The site stays plain HTML. Tweakfast is one script line on each page; take it away and the site is as it was.
5. Readers never see Tweakfast.
